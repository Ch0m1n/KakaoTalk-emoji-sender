# 구현 및 제한

카카오톡 Windows의 이미지 표시 경로에 Frida로 연결해 GIF·WebP를 채팅창에서 반복재생하는 개인용 실험 프로젝트다. 카카오 공식 제품이 아니다.

원본 다운로드, 기존 GIF/WebP 보충, 동시 요청 최대 4개, 원본 자동 발견, 프레임 디코딩, 화면 매칭, 도우미 재연결, GUI 및 진단 ZIP 기능을 포함한다.

내부 함수 주소와 객체 구조는 특정 x86 카카오톡에서 분석한 값이다. 모든 버전 지원을 보장하지 않는다. 설치 파일은 수정하지 않지만 실행 중인 프로세스에 코드를 연결한다. 안전 검사 실패를 무시해서 실행하지 않는다.

4K 최적화: V8 런타임, CModule 픽셀 추출/비교/해시, 최소 자체 갱신 간격 34ms. 현재 소스는 채팅 내용 영역 갱신 개선도 포함한다. 실제 FPS, CPU 개선율 및 모든 DPI 환경을 보장하지 않는다.

메모리·파일 크기·원본 수 제한이 있으며 긴 애니메이션은 프레임을 샘플링할 수 있다. 원본/프레임 디스크 캐시 자동 정리는 아직 없다. 썸네일 매칭은 메시지 ID 기반이 아니므로 유사 이미지·특수 크롭에 제한이 있다.

사용자별 실행 상태, 메시지/이미지, 로컬 조사 기록과 메모리 덤프는 저장소에 포함하지 않는다.
