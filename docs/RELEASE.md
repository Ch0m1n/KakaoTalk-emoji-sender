# AgitCon 2.0.4

- 연결된 카톡 대화창을 최소화·숨김·종료하면 플로팅도 숨겨요. 파일 첨부 대기, 보조창, 창 이동 때문에 일반 감시를 쉬는 동안에도 먼저 확인해요. 플로팅을 끈 독립 창은 유지해요.
- 신형 카톡에서 안내 문구를 한 주기에 두 번 덮어쓰던 처리를 제거했어요. 같은 문구는 다시 쓰지 않아요.
- 신형 입력창을 못 찾을 때도 접근성 탐색 간격을 적용해요. 포커스 후보는 750ms, 전체 탐색은 3초 간격이에요. 포커스 전환 시 다시 확인하되 붙여넣기 직전의 대상·선택 영역 검증은 유지해요.
- 신형 카톡 더블콘·9분할에도 GIF와 공통 파일 선택 경로를 사용해요. 비어 있는 파일 이름 칸에 원본 두 개 또는 분할 이미지 아홉 개를 순서대로 지정해요. **열기와 전송은 직접 눌러 묶음·순서를 확인해주세요.** 자동 전송하지 않아요.
- 신형 롱콘의 확인된 이미지 전송 팝업과 일회 전송 보호를 회귀 검사했어요. 기존 움짤 바로 전송 선택과 롱콘 연속 전송 동작은 유지해요.
- 카톡 움짤 자동재생의 상세 통계 수집을 500ms에서 1초 간격으로 줄였어요. 생존 확인·다운로드 감시는 500ms를 유지하고 원본 애니메이션의 시간 간격은 바꾸지 않아요.

## 다운로드

x64/x86 설치형 Setup과 포터블 ZIP을 함께 제공해요. 기존 앱은 설정 → 업데이트에서 받을 수 있어요. 포터블은 ZIP 전체를 풀고 AgitCon.exe를 실행하세요.

## 확인한 범위

제보 영상의 57개 연속 프레임 비교에서 안내 문구 영역은 40번 바뀌었고 헤더는 바뀌지 않았어요. 코드에서 한 주기의 두 번 쓰기를 확인하고 제거했어요.

실행 중 자동재생기가 이미 기록한 수치를 약 19초 읽었어요. 움짤 하나에서 프레임 변화 125회, 전체 탐색 23~41ms가 관찰됐어요. 원본 프레임 간격을 대조하지 않아 프레임 누락이나 개선된 FPS를 확정하지 않아요. 탐색·통계 부하를 줄인 뒤 실제 체감 확인이 필요해요.

x86/x64 자체 검사에서 더블콘의 GIF·PNG 원본 보존과 순서, 9분할 경로, 롱콘 순서·중단·중복 전송 방지, 접근성 탐색 간격, 상태 문구 중복 갱신, 숨긴 대상과 비활성 대상 구분을 검사해요. 설치·업데이트·자동재생 회귀 검사는 배포 CI에서도 실행해요.

실제 카톡을 조작하거나 메시지를 보내는 시험은 이번에 하지 않았어요. 26.10.0.492의 실제 더블콘·9분할·롱콘 첨부와 최소화·복귀 동작은 먼저 나와의 채팅에서 확인해주세요. 접근성 구조나 대상이 예상과 다르면 자동 재시도 없이 중단해요. 내장 UI 정의와 개인 분석 자료는 배포하지 않아요.
