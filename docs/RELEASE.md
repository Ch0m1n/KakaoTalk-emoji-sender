# AgitCon 2.0.6

- 100×100 옵션을 켠 9분할·더블콘 첨부에서 ‘분할 파일 경로가 올바르지 않아요’로 멈추던 문제를 수정했어요. 축소 캐시는 내용별로 보관하되, 실제 첨부할 파일은 하나의 배치 폴더에 원래 순서와 이름으로 모아요.
- 기존의 ‘같은 폴더·중복 없는 경로·정확한 파일 수’ 검증은 유지해요. 축소를 끄면 기존 파일 경로를 그대로 사용해요.
- 롱콘에서 확인창 전환 중 Windows 전경 창이 잠깐 없는 경우에만 최대 500ms 기다려 다시 확인해요. 기다리는 동안 입력·전송을 요청하지 않아요. 다른 앱·다른 방·프로세스 변경·취소가 확인되면 즉시 중단하고 이미 요청한 조각은 재시도하지 않아요.
- 롱콘 중단 로그에 포커스 전환, 외부 창, 방 식별, 선택 상태, 프로세스 변경을 구분하는 진단을 추가했어요. 대화 내용은 읽거나 기록하지 않아요.

- 업데이트 도우미의 실행 파일 경로 확인을 프로세스 모듈 열람에서 QueryFullProcessImageName으로 바꿨어요. 제한된 조회 권한으로 32·64비트 사이의 경로를 확인하고, 생성 시각·예상 경로 검증은 유지해요. 준비 중 실패했을 때 기존 파일이 이미 변경된 것처럼 안내하던 문구도 고쳤어요.
- 네이티브 입력창 탐지를 한 번의 물리 좌표 범위에서 실행해 부모 채팅창과 DPI 기준이 다른 RichEdit 입력창도 같은 좌표로 비교해요. 플로팅 배치·사용자 지정 위치는 앱 좌표로 변환하고, 좌표 변환 실패 시 창 이동을 건너뛰어요. 앱 자체 DPI 모드나 화면 배율은 바꾸지 않아요.

## 다운로드

x64/x86 설치형 Setup과 포터블 ZIP을 함께 제공해요. 기존 앱은 설정 → 업데이트에서 받을 수 있어요. 포터블은 ZIP 전체를 풀고 AgitCon.exe를 실행하세요.

## 확인한 범위와 남은 확인

100×100 변환 후 실제 다중 첨부 경로 검증까지 연결해 9분할과 GIF·PNG 더블콘의 공통 폴더·파일 이름·순서·100×100 크기·원본 보존을 검사해요. 이전 2.0.5 검사는 변환 결과와 순서까지 확인하고 최종 다중 파일 경로 조건을 빠뜨렸어요. 그 누락을 회귀 검사에 포함했어요.

롱콘은 100×100 네 조각 사전 준비, 잠깐의 전경 창 부재 후 재확인, 대기 시간 초과, 다른 앱 전환 시 추가 붙여넣기·전송 금지, 기존 중단·취소·중복 요청 방지 검사를 실행해요.

제보된 롱콘 로그에는 Qt의 다음 조각 시작 직전 중단이 기록돼 있지만, 기존 진단만으로 구체적인 실패 조건을 확정할 수 없었어요. 이번 제한 대기가 실제 증상을 해결했는지는 아직 확인 전이에요. 나와의 채팅에서 100×100을 켜고 새 네 조각으로 확인해주세요. 다시 멈추면 새 longcon-last.txt의 context 항목으로 원인을 구분할 수 있어요. 실제 카톡 조작·메시지 전송 시험은 이번에 하지 않았어요.

업데이트 식별 검사는 별도 시험 프로세스로 x86/x64 조회자·부모의 네 조합, 생성 시각과 잘못된 경로 거부를 확인해요. 설치·업데이트 시험에서는 반대 비트수의 이전 앱을 사용해 실제 도우미 인계도 검사해요. 구버전 도우미에서 이미 오류가 나는 PC는 이번 한 번 Setup을 직접 실행하거나 새 포터블 ZIP 전체로 교체해주세요. 설치형의 구버전 앱은 자기 폴더의 구버전 도우미를 실행하므로 다운로드만으로 그 도우미가 먼저 고쳐지지 않아요.

DPI 검사는 서로 다른 인식 모드의 부모창·RichEdit을 만든 시험 프로세스, 호출 스레드의 DPI 모드 변화, 100~400% 좌표 계산과 음수 화면 원점, 앱 UI 100/150/200%에서 탐지·왕복 변환·글꼴과 창 크기 보존을 확인해요. 실제 Windows 화면 설정은 변경하지 않았고, 친구 PC의 실제 150% 카톡은 검증 전이에요.
