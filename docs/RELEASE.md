# AgitCon 2.0.3

- 신형 Qt 카톡의 GIF 원본 파일 첨부 경로를 추가했어요. Ctrl+T, Windows 파일 선택창과 Qt 파일 선택창의 파일 이름 칸·열기 버튼을 검증해요.
- 신형 파일 선택창의 1×1 모달 보조 창과 별도 대화상자 스레드를 처리해요. 기존 입력을 덮어쓰지 않고, 선택한 경로를 다시 확인한 뒤 한 번만 열어요.
- 기존 ‘움짤 바로 전송’ 설정을 유지해요. 꺼져 있고 파일 전송 전 확인 설정을 읽지 못하면 파일을 지정하고 ‘열기’를 직접 누르도록 안내해요.
- 신형 롱콘은 조각을 미리 준비하고, 새로 나타난 클립보드 이미지 전송 팝업의 빈 설명란·전송 버튼·대상·포커스를 확인해 빠르게 이어 보내요.
- Qt 내부 팝업은 채팅창과 같은 핸들을 쓸 수 있어 확인된 전송 버튼을 UI 접근성 API로 호출해요. 채팅 입력창에 Enter를 보내지 않아요. 기존 카톡의 대상 창 Enter 경로는 유지해요.
- 각 확인창은 한 번만 요청해요. 팝업이 바뀌거나 닫힘·입력창 복귀를 확인하지 못하면 자동 재시도 없이 중단해요.

## 다운로드

x64/x86 설치형 Setup과 포터블 ZIP을 함께 제공해요. 기존 앱은 설정 → 업데이트에서 받을 수 있어요. 포터블은 ZIP 전체를 풀고 AgitCon.exe를 실행하세요.

## 확인한 범위

26.10.0.492의 내장 UI 정의만 읽어 Ctrl+T, 클립보드 이미지 창, 파일 행의 접근성 이름·1개 전송 버튼, 숨은 모달 창 구조를 대조했어요. 마우스·키보드·메시지·사용자 작성 문장은 조작하거나 읽지 않았어요. 내장 Qt 리소스와 분석 파일은 배포하지 않아요.

자체 가짜 메타데이터와 동작으로 잘못된 팝업·원래 입력창·선택 영역·중복 버튼·파일 이름·전송 개수·중단·중복 요청 방지, 2/4/9/20조각 순서를 검사해요. x86/x64의 기존 회귀·자동재생·설치·업데이트 검사는 배포 CI에서 진행해요. 실제 카톡에 GIF를 첨부하거나 롱콘을 전송한 시험은 아직 하지 않았어요. 먼저 나와의 채팅에서 확인해주세요.

접근성 정보가 제공되지 않거나 예상한 확인창과 다르면 중단해요. Qt 9분할·더블콘 파일 첨부와 작성 문장 읽기는 아직 별도 지원 전이에요.
