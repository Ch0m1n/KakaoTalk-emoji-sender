# AgitCon 2.0.2

- 9분할·더블콘·롱콘 버튼을 제목 아래 같은 스타일로 배치해요.
- 자동재생의 별도 창·트레이를 제거했어요. 설정 → 움짤 자동재생에서 시작·중지·상태·사진 표시 옵션·진단을 바로 사용해요. 설정창을 닫아도 재생은 유지돼요.
- 트레이의 아지트콘 열기는 일반 창으로 유지하고, 플로팅 창은 카톡 앞에 표시해요. 입력창 탐지 실패로 팔레트까지 사라지던 동작을 고쳤어요.
- 구형 KakaoTalk.exe뿐 아니라 신형 26.10.0.492의 KakaoTalkUI.exe도 인식해요.
- 구형 입력창은 채팅방 안의 유일한 쓰기 가능한 입력란을 확인하고, 첨부 직전 포커스를 다시 검증해요. 큰 입력란도 식별해요.
- 신형 Qt 입력창의 접근성 메타데이터·선택 상태가 제공될 때 정지 이미지 Ctrl+V를 요청하는 경로를 추가했어요. 작성 문장이나 채팅 기록을 읽는 경로는 추가하지 않았어요.
- 입력창 미확인·포커스 변경·클립보드 변경 안내를 구분해요.

## 다운로드

설치형 Setup과 포터블 ZIP을 x86/x64로 제공해요. 일반적인 64비트 Windows는 x64를 받으세요. 포터블은 전체 ZIP을 풀고 AgitCon.exe를 실행하세요. 기존 앱의 설정 → 업데이트에서도 받을 수 있어요.

## 검증과 제한

자체 화면 밖 컨트롤로 통합 설정·수명·옵션 저장·일반/플로팅 전환·입력란 탐지·선택 영역 보호·접근성 대상 보존·4K 물리 좌표 조건을 검사했어요. 두 아키텍처의 기존 회귀·자동재생 엔진·설치/업데이트/제거 검사는 배포 CI에서 진행해요. 이번 수정에서 실제 카톡 화면 조작이나 전송은 하지 않았어요. 신형 26.10.0.492의 실제 정지 콘 미리보기는 아직 미검증이에요.

Qt가 선택 상태를 제공하지 않으면 복사만 해요. Qt GIF·9분할·더블콘 파일 첨부, 롱콘 자동 전송, 작성 문장 읽기는 아직 미지원이에요. 기존 카톡의 해당 경로는 유지해요. 자동 전송 모드의 기본값을 변경하지 않았어요.
