# AgitCon 2.0.5

- 설정 → 전송에 ‘100×100으로 축소해서 보내기’를 추가했어요. 기본은 꺼짐이고 선택은 재실행 후에도 유지해요.
- 켜면 정지 이미지와 움직이는 콘의 첨부용 사본을 100×100으로 만들어요. 비율을 유지하고 남는 공간은 여백으로 채워요. 100픽셀보다 작은 이미지는 확대하지 않고 여백을 넣어요.
- GIF와 WebP 움짤은 GIF로 준비하며 움직임·프레임 간격·반복 설정을 유지해요. GIF 변환 특성상 반투명 가장자리는 단일 투명도로 표현해요.
- 더블콘·롱콘·9분할의 각 첨부 이미지에도 적용해요. 원본 파일 복사에는 적용하지 않고 원본 이미지와 팩 경로·별칭을 보존해요.
- 만들어둔 축소 사본은 원본 내용별로 재사용해요. 설정 → 캐시의 ‘전송용 축소·9분할·합성 임시 이미지’로 다음 실행 시 정리할 수 있어요.
- 일반 첨부·움짤 바로 전송·롱콘의 기존 전송 방식과 사용자 선택은 유지해요. 이 옵션 자체로 자동 전송을 켜지 않아요.

## 다운로드

x64/x86 설치형 Setup과 포터블 ZIP을 함께 제공해요. 기존 앱은 설정 → 업데이트에서 받을 수 있어요. 포터블은 ZIP 전체를 풀고 AgitCon.exe를 실행하세요.

## 검증 범위

생성한 로컬 PNG·GIF·WebP로 100×100 크기, 가로·세로 비율과 여백, 작은 원본, 투명도, 서로 다른 DPI, 프레임·간격·반복 설정, 입력 제한과 원본 해시 보존을 검사해요. 실제 배포 Python/Pillow와 앱으로 옵션 저장·구버전 기본값·설정 체크박스, 이미지 클립보드 데이터 크기, 캐시 재사용, 움짤 파일 목록, 더블콘 순서·9분할 9개·롱콘 사전 준비를 함께 검사해요.

시험은 별도 폴더와 메모리 안의 클립보드 데이터로 수행해요. 시스템 클립보드·카톡 입력·메시지 전송은 조작하지 않아요. 카톡이 표시하는 말풍선 크기는 클라이언트가 결정하므로 파일이 100×100이어도 화면 표시 크기가 정확히 100픽셀이라고 보장하지 않아요. 실제 카톡 첨부 결과는 먼저 나와의 채팅에서 확인해주세요.
