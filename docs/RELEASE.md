# AgitCon 2.0.0

- 콘 전송과 GIF/WebP 자동재생을 하나의 앱·트레이·설정·업데이트로 통합했어요.
- x86/x64 설치 파일을 각각 제공해요. 일반적인 64비트 Windows는 x64를 받으세요.
- 설치판은 시작 메뉴·프로그램 제거·선택형 로그인 자동 실행을 제공해요.
- 예전 압축판의 설정·별칭·받은 콘을 원본 보존 방식으로 가져올 수 있어요. 설치판 업데이트/제거는 사용자 데이터와 선택 모델을 유지해요.
- 자동재생 v11.3.0 및 머지 PR #2를 반영하고, 미머지 성능 PR #1의 DIB 캐시·잘림 매칭·작은 GIF 대체 디코딩을 통합했어요.
- 설치판의 업데이트 버튼은 같은 비트 수의 새 설치 파일을 검증해 설치해요. 기존 압축판용 ZIP 업데이트도 유지해요.

## 확인한 범위

x86/x64 자체 런타임·GDI/Frida 재생·픽셀·크롭·다운로드 큐, 콘 전송 보호·DPI·롱콘 회귀, 격리된 설치/업데이트/제거 후 설정·모델 보존을 검사했어요. 카톡 대신 자체 시험 프로세스를 사용했어요. 실제 32비트 OS·친구 PC 4K·이번 통합본의 실제 카톡 전송은 미검증이에요. Qt 64비트 카톡은 자동재생 경로가 있으며 콘 자동 첨부까지 검증됐다는 뜻은 아니에요.

## 설치

기존 자동재생 도우미를 완전히 종료하고 해당 도우미의 자동 시작도 해제하세요. Setup 파일을 실행한 뒤 설정 → 움짤 자동재생에서 시작하세요. x86/x64는 앱/런타임 비트 수예요. 세부 호환성과 제한은 README를 참고하세요.

## 유지보수

version.json을 올리고 소스 변경을 커밋한 뒤 같은 버전의 v 태그를 push하면 두 아키텍처 CI가 성공한 후 설치 파일·압축판 업데이트 ZIP·SHA-256을 게시해요. 설정·콘 원본·로그·개인 경로·모델을 저장소/배포물에 포함하지 마세요.
