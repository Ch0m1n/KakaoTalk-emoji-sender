# AgitCon 2.0.1

- 제목 아래에 콘 9분할·더블콘·롱콘 버튼을 한 줄로 배치했어요.
- 세 버튼의 색·높이·간격을 통일하고, 일반 창과 플로팅 창에서 헤더가 잘리지 않게 맞췄어요.
- 팩 관리·새로고침·설정은 아래 보조 메뉴로 유지해요. 전송 방식은 바뀌지 않았어요.

## 다운로드

64비트 Windows는 x64, 32비트 Windows는 x86을 선택하세요. 설치형 Setup과 설치 없이 쓰는 포터블 ZIP을 모두 제공해요. 포터블은 ZIP 전체를 풀고 AgitCon.exe를 실행하세요.

## 검증

실제 앱 컨트롤로 일반·플로팅 화면을 화면 밖에서 렌더링해 버튼 배치를 확인했어요. 복사·첨부 상태 초기화와 UI 배율 회귀 검사도 통과했어요. 배포 CI에서 x86/x64 기존 회귀·자동재생 엔진·설치·업데이트·제거 검사를 진행해요. 이번 디자인 변경을 검증하면서 실제 카톡 전송이나 사용자 화면 조작은 하지 않았어요.
